# 🌸 เว็บแอปพลิเคชัน "ลอยกระทงออนไลน์ ๒๕๖๙" 
## วิทยาลัยเทคนิคท่าหลวงซีเมนต์ไทยอนุสรณ์ (Thaluang Cement Thai Anusorn Technical College)

เว็บแอปพลิเคชันสำหรับกิจกรรมสืบสานประเพณีลอยกระทง ขอขมาพระแม่คงคา แบบรักษ์โลก ๑๐๐% ปราศจากขยะในแม่น้ำป่าสัก ออกแบบด้วยธีมสีม่วง น้ำเงิน ทอง และส้ม ให้ความรู้สึกอบอุ่น สวยงาม ทรงคุณค่า และเต็มไปด้วยชีวิตชีวาตามเอกลักษณ์ความเป็นไทย

---

### 🌟 คุณสมบัติเด่นของระบบ (Key Features)

1. **รูปแบบการออกแบบ (UI/UX)**
   - **ธีมสีเอกลักษณ์:** ม่วงอินทนิล, น้ำเงินรัตติกาล, ทองอร่าม และส้มเปลวประทีป
   - **บรรยากาศเสมือนจริง:** ท้องฟ้าคืนวันเพ็ญเดือนสิบสอง พระจันทร์เต็มดวงส่องแสงนวล คลื่นน้ำสะท้อนแสงจันทร์ โคมลอยยี่เป็ง และหิ่งห้อยเต้นระบำริมน้ำ
   - **กราฟิกและแอนิเมชัน:** Canvas 2D เรนเดอร์สายน้ำ คลื่นกระเพื่อม เปลวไฟเทียนกะพริบ ควันธูป และพลุดอกไม้ไฟ
   - **Responsive Design:** ใช้งานได้ลื่นไหลทั้งสมาร์ตโฟน แท็บเล็ต และคอมพิวเตอร์
   - **ภาษาไทยทั้งหมด:** ครบถ้วนด้วยถ้อยคำมงคล บทสวดขอขมา และข้อมูลแผนกวิชาของวิทยาลัยฯ

2. **ระบบสร้างและปรับแต่งกระทง (Krathong Customizer)**
   - **รูปแบบกระทง 5 ชนิด:**
     1. กระทงใบตองวิจิตร (ศิลปะการพับกลีบใบตองไทยแท้)
     2. กระทงดอกบัวสวรรค์ (กลีบบัวหลวงผลิบานบริสุทธิ์)
     3. กระทงขนมปังรักษ์โลก (รูปเต่า/ปลา เป็นมิตรต่อสัตว์น้ำ)
     4. กะลาสายประทีป (กะลามะพร้าวและเทียนชัยสไตล์สุโขทัย)
     5. แฟนตาซีช่างเทคนิคท่าหลวงฯ (ผสานเฟืองทองคำและระบบไฟ LED ดิจิทัล)
   - **ปรับแต่งสีและลวดลาย:** เขียวตองสด, ทองอร่าม, ม่วงอินทนิล, ชมพูกลีบบัว, ส้มประกายแสด, ฟ้าคราม
   - **ดอกไม้ประดับใจกลาง:** บัวชมพู, บัวขาว, ดาวเรือง, กล้วยไม้, กุหลาบ
   - **เครื่องสักการะ:** เทียนชัย 4 เฉดสี, ธูป 3 ดอกพร้อมควันลอย, เหรียญมงคล ๙ บาท, โบว์ริบบิ้นทอง
   - **Live Preview:** แสดงผลตัวอย่างกระทงเวกเตอร์ SVG หมุนวนลอยน้ำแบบสดๆ ก่อนตัดสินใจ

3. **ระบบเขียนคำอธิษฐาน & เลือกตัวละคร**
   - ระบุชื่อ หรือเลือก "ไม่ระบุตัวตน (Anonymous)" เพื่อความเป็นส่วนตัว
   - เลือกระดับและบทบาท (ปวช., ปวส., ครูอาจารย์, บุคลากร, ศิษย์เก่า, บุคคลทั่วไป)
   - เลือกแผนกวิชาครบทั้ง 11 แผนกของวิทยาลัยเทคนิคท่าหลวงซีเมนต์ไทยอนุสรณ์
   - เลือกตัวละครอวาตาร์ (นักเรียนชาย, นักเรียนหญิง, ครูอาจารย์, ชุดไทยประยุกต์, มาสคอตน้องเฟืองทอง) หรืออัปโหลดรูปภาพส่วนตัว
   - คำอวยพรยอดนิยมกดคลิกเดียวเติมข้อความอัตโนมัติ

4. **ระบบลอยกระทงและการ์ดอวยพรออนไลน์**
   - เมื่อกดลอย กระทงจะเคลื่อนตัวลงสู่แม่น้ำป่าสักพร้อมวงน้ำกระเพื่อม
   - เอฟเฟกต์พลุดอกไม้ไฟเฉลิมฉลองและโคมลอยลอยขึ้นสู่ฟากฟ้า
   - สร้าง **"บัตรอวยพรลอยกระทงดิจิทัล" (Blessing Card)** ความละเอียดสูง (1080x1080 px) ประทับตราวิทยาลัย
   - ดาวน์โหลดการ์ดเป็นไฟล์รูปภาพ PNG หรือแชร์ไปยัง LINE, Facebook, X (Twitter) และคัดลอกลิงก์ได้ทันที

5. **ระบบเปลี่ยนธีมแม่น้ำและฉากหลัง (3 ฉาก)**
   - **ริมน้ำป่าสัก คืนจันทร์เพ็ญ:** พระจันทร์ดวงโต ผิวน้ำสะท้อนแสงสีทอง
   - **หน้าวัดไทยงานสมโภช:** พระเจดีย์ทองอร่าม ไฟประดับงานวัด และธงราวหลากสี
   - **ท่าน้ำวิทยาลัยเทคนิคท่าหลวงฯ:** ศาลาท่าน้ำประดับโคมไฟประจำสถาบัน

6. **ระบบเสียงและดนตรี (Web Audio API Synthesizer)**
   - สังเคราะห์ทำนองเพลงไทย "วันเพ็ญเดือนสิบสอง" (Loy Krathong Theme) ด้วยเสียงระนาด/ขิม
   - เสียงน้ำไหลคลอเบาๆ (Stream water ambient)
   - เสียงเอฟเฟกต์: เสียงวางกระทงลงน้ำ (Splash), เสียงระฆังวัด (Temple Bell), เสียงพลุระเบิด (Firework), เสียงเขย่าเซียมซี (Siamsi Rattle)
   - ควบคุมเปิด/ปิดเสียงและแสดงแถบคลื่นเสียงเคลื่อนไหว

7. **บรรยากาศงานวัดจำลอง (Virtual Temple Fair)**
   - **ซุ้มเซียมซีแม่นๆ:** เขย่ากระบอกเซียมซีแบบแอนิเมชัน มีเสียงไม้กระทบ พร้อมบทกลอนทำนายดวงชะตา ความรัก การเรียน และเลขนำโชค
   - **ซุ้มของกินและขนมไทยโบราณ:** ผัดไทยเตาถ่าน, ขนมครกชาววัง, ลูกชิ้นปิ้งน้ำจิ้มมะขาม, ไอติมหลอด 7 สี, สายไหม, น้ำจรวดซ่า กดชิมเพื่อรับแต้มบุญ
   - **ซุ้มสอยดาวการกุศล:** สอยดาวลุ้นคำอวยพรและของขวัญมงคล

8. **ระบบสถิติเรียลไทม์ & ฐานข้อมูลแอดมิน**
   - สถิติจำนวนกระทงรวม ผู้เข้าร่วม และกระทงที่กำลังลอยอยู่ในสายน้ำ
   - อันดับการร่วมกิจกรรมแยกตามแผนกวิชา (Department Leaderboard)
   - แดชบอร์ดแอดมิน (PIN: `1234`) ค้นหา กรอง ซ่อน ลบ และส่งออกข้อมูลเป็น CSV / JSON

### 💻 วิธีการเปิดใช้งาน

#### วิธีที่ 1: รันผ่าน Python Launcher (แนะนำ)
เปิด PowerShell หรือ Command Prompt เข้าไปที่โฟลเดอร์นี้ แล้วสั่ง:
```bash
py -3 run_server.py
```
โปรแกรมจะเปิดเบราว์เซอร์ไปยัง `http://localhost:8000` ให้อัตโนมัติทันที

#### วิธีที่ 2: เปิดไฟล์ตรงผ่าน Web Browser
สามารถดับเบิลคลิกเปิดไฟล์ `index.html` ผ่าน Google Chrome, Microsoft Edge หรือ Safari เพื่อใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ
